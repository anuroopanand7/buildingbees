# Demo video script (3 minutes or less, public YouTube)

Record with "NVIDIA Nemotron" selected on the start screen. Use the "Book a haircut" starter idea. The rules ask the video to show Nebius Token Factory and Nemotron in use, so say both names and show the engine choice.

| Time | On screen | Say |
|---|---|---|
| 0:00 to 0:15 | A one-prompt tool producing screens from one sentence | "AI can turn one sentence into an app. But one sentence leaves most decisions out, so the tool guesses." |
| 0:15 to 0:30 | BuildingBees start screen. Click "NVIDIA Nemotron" | "BuildingBees asks first. It runs on NVIDIA Nemotron 3, served by Nebius Token Factory." |
| 0:30 to 0:55 | Click "Book a haircut", then "Map it". Flow appears. Scout Bee message with its sources | "First a Scout Bee searches the web with Tavily. Then Nemotron draws the user flow. No screens yet, because nothing is agreed." |
| 0:55 to 1:20 | A question with "From the Scout Bee's reading" under it. Click the source, then answer | "This question came from a real page about salon no-shows. I answer, and Nemotron redraws the board in about two seconds." |
| 1:20 to 1:40 | Type "whatever is normal". The bee asks again | "If I am vague, it does not accept it. It asks again, more precisely." |
| 1:40 to 2:10 | Click "Draw the screens". Screens with wireframes, buttons, APIs | "Now the bigger model, Nemotron 3 Ultra, draws every screen, button and API from what we agreed. Super for the fast replies, Ultra for the heavy reasoning." |
| 2:10 to 2:30 | Open one screen. Answer one question. Readiness moves | "A screen is ready to build only when nothing is left to guess." |
| 2:30 to 2:50 | Click "Brief". Scroll to Research and Still open. Copy agent link | "The Brief has every decision, every source, and everything still undecided. One link for my engineers or my coding agent." |
| 2:50 to 3:00 | Logo, live URL, GitHub | "BuildingBees. Other tools guess. We ask. Built on NVIDIA Nemotron, Nebius Token Factory and Tavily." |

Before recording: rehearse the vague-answer step, hard-refresh, click "New spec", notifications off, zoom 100%.
