BuildingBees is an AI product team that asks before it builds. One-prompt tools guess whatever your idea leaves out. BuildingBees draws the user flows first, then six bees (product, design, frontend, backend, testing, compliance) ask what is missing, one question at a time. A vague answer gets a sharper follow-up. A clear answer redraws the board. Only then are screens, buttons and APIs drawn, and you get a Brief with every decision and everything still undecided.

Gemini (Gemini API, structured output, native PDF input, model fail-over) draws the flows, reads every answer and draws the screens. Cloud Run hosts the app, scaled to zero when idle, built with Cloud Build. Firestore saves every board after each change, so a board and its Brief link survive restarts. Firebase Authentication (Sign in with Google) gives each person their own list of boards on any device.

Live, tested (31 automated tests), MIT licensed.
